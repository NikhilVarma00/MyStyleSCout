# MyStyleScout - Compare Sneakers, Find. Compare. Save.

Live: https://www.mystylescout.in

India's sneaker deal finder. Compares prices for the same shoe across Amazon, Flipkart, Myntra etc.

### Features
- Short titles on cards, full titles on detail pages
- Search, Filter (Brand/Store/Price/Discount) & Sort (Best Deal)
- Quick View modal
- 96/100 PageSpeed on Desktop

### Tech Stack
HTML + Vanilla JS (script.js) + product.json catalog

### How it works
Static JSON catalog → Rendered with Vanilla JS → Filter/Sort on client side
